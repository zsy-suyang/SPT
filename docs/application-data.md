# Application spectra and source files

Each cohort has a directory at `datasets/applications/<cohort>/`, containing `prepared.csv`, `reference_predictions.csv`, `provenance.json` and source files. Its descriptor models are located at `checkpoints/applications/<cohort>/`. `configs/applications.json` maps each cohort and descriptor to its model; `configs/registry.json` gives the model's configuration and weight paths.

`prepared.csv` is a long table: one spectrum has 256 rows in `point_index` order, with `spectrum_id`, `absorber`, `energy_eV` and `intensity` columns. Energy referencing and resampling are complete; the inference loader applies the normalization specified by each model configuration.

For computed Li–Co–O, the source-group table uses zero-based row numbers in `raw/computed_Li_Co_O_all_26_sites.csv`; `prepared.csv` and `reference_predictions.csv` retain the same `source_row` and `site` identifiers. All 26 source records were checked against the original calculation export. Group names are source-directory identifiers, not verified assignments to individual files in the public structure repository.

The Li–Co–O measured cohort uses the [LiCoO₂ LISA reference](https://lisa.iom.cnr.it/xasdb/data/LiCoO2_80K_111.xdi). Its study-level data record identifies the source study; the processed spectra used here were supplied by the authors. Source files from published repositories retain their own attribution and licence terms.

`reference_predictions.csv` contains the descriptor results for each cohort; the available descriptors are listed in [Application commands](applications.md). For Co standards and Fe charging, these include the clean predictions used in the sensitivity comparisons. Experimental labels and structural references are identified separately from model predictions.

See [applications.md](applications.md) for cohort inference commands and [reproduce.md](reproduce.md) for the computed benchmark and intervention experiments.
